Cómo escribirlo desde un iPhone o cualquier celular
  1. Baja la app gratis NFC Tools.
  2. Entra a Escribir → Añadir un registro → URL / URI.
  3. Pega el enlace de arriba y toca Escribir.
  4. Acerca el chip a la parte de atrás del celular hasta que diga que terminó.
  5. Prueba: acerca otro celular. Debe abrir el perfil del cliente.
Pasos para cada cliente (en 3 minutos)
  1. El cliente se registra y elige su usuario.
  2. Escribe ese usuario aquí. Debe salir su nombre en verde.
  3. Descarga la etiqueta y mándala a tu Niimbot.
  4. Escribe el chip con el enlace de arriba y pruébalo.
  5. Pega el chip en el lugar donde el cliente lo vea y, encima, la etiqueta. Escanéala tú con tu cámara como prueba final.
Consejos para que dure y funcione
  1. El chip no funciona bien pegado directo sobre metal: pégalo en vidrio, plástico, madera o cartón, o usa chips «para metal».
  2. Bloquear el chip (solo lectura) es para siempre. Hazlo solo después de probar que abre bien.
  3. Si el cliente cambia de usuario, el QR y el chip dejan de servir: avísale que no lo cambie.
